# metal-tree-3d — 制作記録

## 企画書（企画部長）
- **実験**：金属樹（中学3年「化学変化とイオン」／金属のイオンへのなりやすさ）
- **タイトル**：化学のクリスマスツリー | Metal Tree Bench
- **前回の却下からの学び**：結果がわかりきっていて遊ぶ仕掛けがなかった → 今回は **「育てる・飾る・写真を撮ってシェアする」** を中心にする
- **遊び方**
  1. ツリーの形に曲げた金属の線（銅・亜鉛・マグネシウム）と、水溶液（硝酸銀・硫酸銅・硫酸亜鉛・硫酸マグネシウム）を選ぶ
  2. 水溶液に入れると、タイムラプスで **金属の結晶が枝のように伸びてツリーになる**
  3. 星をのせる・ライトアップで飾り、**「写真を保存」でツリーの画像をシェア**できる
- **刺さる一瞬**
  - 銅線 ＋ 硝酸銀水溶液：キラキラの **銀の結晶がツリーを覆い**、無色の液が **だんだん青くなる**（2つの変化が同時に起きる）
  - 組み合わせによっては **何も起きない** → 「なぜ？」がイオン化傾向（Mg ＞ Zn ＞ Cu ＞ Ag）につながる
  - 12月の季節ネタ。「#化学ツリー」で作品の写真を集められる
- **HUD**：組み合わせ・イオンの式・イオンへのなりやすさの列・経過時間（タイムラプス120倍）・出てきた金属と溶けた金属の質量 (mg)・水溶液の色・記録

## 化学の根拠（化学監修部長 G1）
- イオンへのなりやすさ：Mg ＞ Zn ＞ Cu ＞ Ag（標準電極電位 −2.37, −0.76, +0.34, +0.80 V）
- 線の金属のほうがイオンになりやすいときだけ反応する
  | 線 \ 水溶液 | 硝酸銀 | 硫酸銅 | 硫酸亜鉛 | 硫酸マグネシウム |
  |---|---|---|---|---|
  | 銅 | Cu + 2Ag⁺ → Cu²⁺ + 2Ag（銀樹・液が青くなる） | 変化なし（同じ金属） | 変化なし | 変化なし |
  | 亜鉛 | Zn + 2Ag⁺ → Zn²⁺ + 2Ag | Zn + Cu²⁺ → Zn²⁺ + Cu（赤褐色の銅・青が薄くなる） | 変化なし（同じ金属） | 変化なし |
  | マグネシウム | Mg + 2Ag⁺ → Mg²⁺ + 2Ag | Mg + Cu²⁺ → Mg²⁺ + Cu | Mg + Zn²⁺ → Mg²⁺ + Zn | 変化なし（同じ金属） |
  - 原子数・電荷とも確認 ✔（例：Cu + 2Ag⁺ → 左辺の電荷 +2、右辺 +2）
- マグネシウムは水溶液中で水とも反応して、水素の泡が少し出る（演出として泡を表示）
- 量的関係（水溶液中の金属イオンはどれも 0.0040 mol として計算。濃度・体積は画面に出さない）
  - 銅 ＋ 硝酸銀：銀 0.0040 mol × 107.87 = **431 mg** 出る、銅 0.0020 mol × 63.55 = **127 mg** 溶ける（質量比 3.39 倍）
  - 亜鉛 ＋ 硫酸銅：銅 254 mg 出る、亜鉛 262 mg 溶ける
- 速さ：イオンへのなりやすさの差が大きいほど速く進むモデル（k ∝ √ΔE）。銅 ＋ 硝酸銀で約1時間に9割（実際の授業でも数十分〜1時間で目に見える樹ができる）
- 水溶液の色：Cu²⁺ が青。硝酸銀・硫酸亜鉛・硫酸マグネシウムは無色

## 安全審査（安全管理部長 G1）
- 薬品名は出すが、**濃度・量・入手方法は書かない** ✔
- 硝酸銀は皮膚につくと黒くなり、目に入ると危険 → 画面の注意書きに加え、ログで「実際の硝酸銀は先生が扱う薬品」と一度表示 ✔
- **鉛樹（酢酸鉛）は扱わない**：鉛は有毒なため ✔
- 「写真を保存」は端末に画像を保存するだけで、外部送信なし ✔
- 画面に「これはシミュレーションです。実際の実験は必ず先生の指導のもとで」を常時表示 ✔
- 既存作品と重複なし ✔

**G1 判定：PASS**
