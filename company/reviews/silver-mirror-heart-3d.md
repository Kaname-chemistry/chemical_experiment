# silver-mirror-heart-3d — 制作記録

## 企画書（企画部長）
- **実験**：銀鏡反応（高校化学「有機化合物」／アルデヒドの還元性・糖類）
- **タイトル**：鏡のハート | Silver Mirror Heart
- **出しどき**：バレンタイン（2/10・2/12・2/14 の3日連載）
- **遊びの仕掛け（却下からの学びを反映）**：**「★3の鏡を作れる？」**
  - 湯の温度・ガラスの洗い方・ゆするかどうか・還元する物質の4つで、鏡の出来ばえ（★0〜★3）が決まる
  - 液を捨てると、ハート形のフラスコの内側が鏡になって現れる
  - メッセージを入れて「写真を保存」→ バレンタインのカードとしてシェアできる
- **刺さる一瞬**
  1. 液を捨てた瞬間、透明だったハートが **ピカピカの鏡** になって現れる
  2. 早く作ろうとして湯を熱くしすぎる・ゆする・ガラスが汚れている → **黒い粉になって鏡にならない**
  3. **砂糖（スクロース）では何も起こらない**のに、果糖（フルクトース）では鏡ができる → 「なぜ？」
- **HUD**：使う物質と判定（還元性の有無と理由）・反応式・湯の温度・経過時間・鏡になった銀／黒い粉の質量 (mg)・出来ばえ（★）・記録

## 化学の根拠（化学監修部長 G1）
- 銀鏡反応：アンモニア性硝酸銀水溶液中のジアンミン銀(I)イオンが還元されて銀が析出する
  - RCHO + 2[Ag(NH₃)₂]⁺ + 3OH⁻ → RCOO⁻ + 2Ag + 4NH₃ + 2H₂O
  - 原子数：Ag 2=2、N 4=4、H 1+12+3=16 / 12+4=16、O 1+3=4 / 2+2=4 ✔ 電荷：+2−3=−1 / −1 ✔
- 物質ごとの判定
  | 物質 | 結果 | 理由 |
  |---|---|---|
  | グルコース（ブドウ糖） | 鏡ができる | 水溶液中で鎖状構造をとり、アルデヒド基（ホルミル基）をもつ → 還元性 |
  | フルクトース（果糖） | 鏡ができる | ケトンの構造だが、塩基性の水溶液中では還元性を示す（教科書どおり） |
  | スクロース（ショ糖・砂糖） | 何も起こらない | グルコースとフルクトースの還元性を示す部分どうしで結合している → 還元性を示さない |
  | アセトン | 何も起こらない | ケトンは還元性を示さない |
- 量：銀イオン 1.0×10⁻³ mol（濃度・体積は画面に出さない）→ 銀は最大 **108 mg**
- 鏡になる条件（教科書の操作どおり）：ガラスをよく洗う／約60 °Cの湯で温める（湯せん）／静かに置く（振り混ぜない）
  - 汚れたガラス：銀がガラスに均一につかず、黒っぽくまだらになる
  - 温度が高すぎる（約80 °C以上）・ゆする：銀が液の中で細かい粒として出て、黒い粉になって沈む
  - 温度が低い：反応が遅い
- 速さのモデル：k ∝ exp(0.06 (T − 60))（演出上の仮定。60 °Cで約5分、25 °Cでは数倍遅い）。鏡になる割合は「洗ったか・温度・ゆすったか」で決める（演出上のモデル）

  - 鏡が暗い → 銀の色と映り込みを明るく
